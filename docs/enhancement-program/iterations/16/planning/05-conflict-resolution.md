# Lens 05 — human resolution of contrary evidence

**Problem and job.** An owner reviewing proposed company guidance must decide whether a governing rule, scoped exception, abandoned discussion and unresolved gap apply before approving it. Success means resolving every predeclared critical conflict with attributable evidence and preserving dissent. A missed governing obligation or unsupported approval falsifies the hypothesis. Iteration 15 recovered the policy alongside contrary history, yet its sole synthesis was scripted and the operator repaired an incomplete obligation [handoff](../../15/handoff-to-16.md), [product retrospective](../../15/retro/product.md). Static export integrity passed while task evaluation stayed blocked [accepted evidence](../../../../../tmp/enhancement-program/15/accepted-evidence01.json).

The existing [WEB component](../../../../../tmp/enhancement-program/16/source-safe/lib/harness_forge_web/components/company/corpus_review.ex) shows original conflict/unknown findings, citation byte spans, saved resolution and a continue button (lines 430–516). Results expose provisional relation, document status, dates, exact context and whether passages entered synthesis (lines 653–752). [Server review](../../../../../tmp/enhancement-program/16/source-safe/lib/harness_forge/company/corpus_review.ex) checks exact claim revision, matching project/goal and current source pins (lines 236–338, 823–845). None determines applicability for the owner.

**Options.** (A) Add a compact conflict worksheet before continuing to exact claim review. Pair each original conflict/unknown with available cited and contrary context, distinguish selected synthesis input from extra candidates, and carry the operator’s applicability note into existing saved resolution. This makes comparison direct but requires careful draft recovery. (B) Deep-link existing findings/context with an unresolved checklist. This is cheaper but keeps reconciliation scattered. Automatic applicability scoring would imply unmeasured semantic authority.

**Recommendation.** Choose A as one WEB review step, reusing current scoped projections and resolution machinery; supporting Elixir only if the current projection cannot supply an existing field. Keep dissent visible after resolution. Present absent context and unknown currentness as reasons to revise, reject or defer. Preserve exact claim and separate plan approvals; the worksheet never approves either. Use named controls, keyboard order, visible focus and a return path from exact context. This is a usability bet, not a semantic-confidence claim.

**Falsifiable criteria for Root to verify:**

1. Given a policy, exception and abandoned discussion, when the owner reviews the claim, then each has exact revision/context and the owner can state applicability before continuing; Root checks public pins and saved resolution.
2. Given contrary evidence outside synthesis or unknown currentness, when resolution is saved, then dissent remains visible without a company-wide coverage claim; Root checks WEB text and server scope.
3. Given a stale claim, changed goal or revoked source, when the owner returns from context or continues, then that revision cannot be approved, the reason is visible and a valid-scope draft is recoverable; Root checks negative paths and focus.

Proposed observation metric: four of five first-time operators identify the applicable rule, remaining uncertainty and both approvals unaided; no novice study has run. Larger-corpus qualification, real-model abstention, obligation-to-task coverage and own-MCP company context remain open [scale direction](../../../SCALABILITY_REUSE.md).
