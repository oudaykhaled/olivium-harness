# 15 — Represent one company obligation as an approved rule

**User, job, hypothesis.** A company operator needs to turn an internal goal into an auditable rule before sharing a harness. Success is a mandatory goal-derived rule the operator can approve, build, export and explain by exact origin. One admitted rule with an unapproved or stale origin falsifies authority; one mandatory goal that still needs a fabricated citation falsifies representability. This is a capability metric, not a measured company-outcome metric. The 04 evidence establishes 440 passes and native static-inspection behavior, while qualified real-model company fitness remains unproven ([handoff](../../04/handoff-to-05.md); [product retrospective](../../04/retro/01-product.md)).

**Choice and evidence.** [Evidence.create_claim](../../../../../lib/harness_forge/evidence.ex) requires citations; [Company.resolve](../../../../../lib/harness_forge/company.ex) pins selected goal content hashes, but selection grants no rule authority. [Harnesses.specification](../../../../../lib/harness_forge/harnesses.ex) emits every rule with `goal_id: nil`. Choose one explicit, versioned goal-origin basis bound to an exact goal content hash and exact claim revision, with a separate operator approval. Recheck it at plan approval, build, export and release eligibility. Existing citation-origin claims and historical artifact bytes retain their contracts. Selecting a goal alone grants nothing.

**Acceptance.**

- Given a selected in-scope goal and separately approved basis for an exact goal hash and claim revision, when the approved plan is built and exported, then the rule carries that origin and the package remains inspectable by exact identity.
- Given a missing, rejected, foreign-workspace or withdrawn basis, when approval, build or export is attempted, then admission refuses before new package/export bytes become visible.
- Given a changed goal, superseded claim or restored quarantine, when dependent admission is retried, then the prior basis has no authority; unrelated citation-origin plans retain eligibility.

**Tradeoffs and ownership.** Declared-conflict admission prevents contradictions but cannot represent a missing obligation; task-route identity helps qualification but crosses execution and preserves the [03 abstention](../../03/decision-amendment.md) until proven. Goal-origin authority is the smaller direct path to the operator's blocked job. Evidence/Decisions own immutable basis and approval; Company owns scope and snapshot checks; Harnesses/release own repeated admission; privacy owns purge/restore invalidation. Risk: users may mistake traceable origin for complete policy coverage. Show it as one approved rule, and require representative task evaluation before any company-fitness claim.
