Harnesses maps that admitted rule to the existing goal ID and empty evidence. Direct builds refuse approved goal claims with `:goal_claim_requires_plan`. Admission detects goal origin from either the artifact rule's goal ID or its current typed claim; missing/contradictory origin, absent binding, invalid plan and changed complete artifact refuse. A current exact valid binding remains sufficient among multiple bindings. Existing planned-build prebinding and repeated transactional checks are retained.

Public reasons supplied to the web author are `:invalid_claim_basis`, `:stale_goal_basis`, `:claim_origin_change`, `:goal_not_selected` and `:goal_claim_requires_plan`; existing workspace/privacy failures keep priority. A missing or foreign goal returns the same generic stale-basis refusal and never exposes foreign metadata. Audit payloads keep the existing safe identifier-only structure.
