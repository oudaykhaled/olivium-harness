### Exact proposed interface (additional handoff contract)

All maps below have string keys; sets are distinct and deterministically sorted. These names are proposed for the conductor's single interface freeze, not claims about existing APIs.

| Boundary | Exact contract |
|---|---|
| `Analysis.analyze(attrs, opts \\ [])` | Only attrs `project_id, source_refs, goal_id, goal_content_hash`; source ref exactly `source_id, revision_id, body_hash`; opts only `run_id, request_id, timeout`. UUID/SHA validation and fixed ADR errors. |
| New basis v1 | Exactly `kind, version, project_id, goal_id, goal_content_hash, context, context_digest, report, guidance, provider, model, config_fingerprint, run_id, request_id, review_resolution`; kind `company_analysis`, integer version `1`. |

Goal and model identity are separately bound by the entire basis hash. No workspace ID inside immutable basis: restore remaps row scope without rewriting origin. |
