## Privacy and live-availability boundaries

Do not reuse that full reload solely for new Inspect/Refresh or selection events; refresh required local records directly. Preserve existing unrelated reload behavior without representing it as readiness evidence.

[Registry.list/0](../../../../../lib/harness_forge/adapters/registry.ex) marks Codex/Claude managed backends unavailable and OpenCode as `opencode_docker`. A selected OpenCode model still leaves live availability unassessed. Historical selected-run reasons may be exposed only through fixed codes, explicitly as that run's observation. ## Portal lifetime and event integration

[PortalLive](../../../../../lib/harness_forge_web/live/portal_live.ex) has separate update paths. Cover each without recomputing readiness in render:

| Trigger | Existing path and readiness effect |
| --- | --- |
| Package selection changes | Clear selected evaluation and prior report immediately. Never retain a report for another digest. |
| Evaluation selection changes | Clear prior report until explicit Inspect/Refresh. Nil means no selection; no newest/best-run inference. |
| Ordinary successful/failed mutation, company change, completed job | `finish/3`, `{:company_changed, _}` and `{:operation_finished, _}` call `reload/1`. Invalidate the cached observation when relevant data reloads. |
| Evaluation timer | `:refresh_evaluations` currently replaces `:runs` only on the Evaluations tab and bypasses `reload/1`. A relevant run refresh must also invalidate readiness; a Packages inspector cannot assume this timer already refreshed its options. Explicit inspection must revalidate through the domain regardless of the list cache. |
| Source/workspace purge or restore | `privacy_result/3` resets the initiating view and broadcasts `:company_cache_reset` to siblings. `handle_info(:company_cache_reset, ...)` resets hidden sibling state then reloads. Clear readiness selection/report on both paths. Restore writes a new quarantined directory and **does not switch the active workspace**. |
| Session revocation/expiry | `revoke_operator/1`, PubSub revocation and timer checks redirect to login. Clear readiness data before redirect. The parent event authentication hook rejects expired events; it must not dispatch inspection/navigation after refusal. |

A stateless function component with parent-owned assigns/events avoids another event-generation cache. If a stateful LiveComponent is used, the existing [CompanyPanel](../../../../../lib/harness_forge_web/components/company_panel.ex) demonstrates why it explicitly checks authentication: LiveComponents do not inherit the parent's event hook. Its random per-mount generation rotates on reset; a reset counter alone cannot reject a captured event from a previous mount. Apply the frozen freshness requirement to any new cached component. Navigation accepts only fixed destinations and never dispatches evaluation, approval, export or another mutation.

Author B identified a separate browser seam: a focused select may retain its client value across a privacy reset even after server assigns clear. Existing `assets/js/app.js` resets only fixed Company form IDs. The recommended owned-file correction is a separate reset-only controls generation in PortalLive, suffixing the inspector select IDs and matching label targets while preserving stable form names/data selectors. Do not rotate this DOM identity on ordinary selection/inspection. Root must verify actual focused package/run values clear after reset; server assigns and stale-event tests alone do not prove browser control clearing. This needs no shared JavaScript change or new authority.

Run dropdown entries must be filtered to the selected digest's active-workspace records and project safe bounded ID/kind/outcome labels. Do not render arbitrary persisted reason/config/scope or JSON. `Artifacts.list/0` currently aborts the entire verified list on one invalid artifact; the direct domain API must still return the safe integrity-blocked report for an explicit digest. This inherited listing behavior does not require shared-source changes for the selected unit.
