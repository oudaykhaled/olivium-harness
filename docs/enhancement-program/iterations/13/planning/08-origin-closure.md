# Origin closure across a retrieved company corpus

**Observed gap.** Origin v1 records examined sources, including uncited ones, and exact citations; analysis still admits only 2–4 whole sources and 32,768 body bytes ([Origin](../../../../../tmp/enhancement-program/13/source-before/lib/harness_forge/evidence/origin.ex#L24), [Analysis](../../../../../tmp/enhancement-program/13/source-before/lib/harness_forge/company/analysis.ex#L169)). Iteration 12’s additional passage inspection remains outside the report origin, so a later contrary policy can leave an approved recommendation apparently eligible ([handoff](../../12/handoff-to-13.md#L13), [study](../../../../../tmp/enhancement-program/11/scale-reuse-steering-01/STUDY.md#L157)).

**Connected change.** Mint an immutable, server-owned retrieval snapshot v2 when a permitted corpus and saved goal are selected. Keep v1 validation intact. Bind workspace/project, membership and authorization generation, goal hash, scan/index/graph generations, retrieval query plan and truncation/coverage, parser/chunker/prompt/model configuration, and a bounded ordered set of support, contrary and unknown passages. Each passage maps to the original source/revision/body hash/exact UTF-8 byte range, parent context, document status and effective versus capture time. Store a pageable manifest of cited/uncited passages, context fields, prior extraction episodes, edge-supporting episodes, and summaries’ recursive source closure. A summary without a complete closure is ineligible for analysis. Digest the canonical snapshot and dependency manifest; the browser submits only an opaque snapshot ID plus expected digest. Resolve the closure from SQLite before each provider dispatch, approval, build and export; never trust graph IDs or client-supplied source lists as authority ([Graphiti `add_episode`](../../../../../../research/harnessforge-graph-rag-study-2026-11-02/sources/graphiti/graphiti_core/graphiti.py#L1334), [study](../../../../../tmp/enhancement-program/11/scale-reuse-steering-01/STUDY.md#L159)).

**Eligibility rule.** Exact human edits produce successor claim revisions with the same immutable snapshot and citations; rejection excludes the rejected revision. A separate exact plan approval still gates deterministic export. A corpus generation change, including *new* contrary evidence with unchanged citations, stales snapshot, claim, plan and artifact eligibility until re-review. Use coarse corpus invalidation first; optimize only after proving contradiction coverage. Tombstone affected summaries and outputs before graph removal and keep denial through failed rebuild or restore. Graphiti’s removal catches a summary rebuild error and restores `old_summary`, so upstream completion alone is insufficient ([Graphiti removal](../../../../../../research/harnessforge-graph-rag-study-2026-11-02/sources/graphiti/graphiti_core/graphiti.py#L2174), [reuse decision](../../../../../tmp/enhancement-program/11/scale-reuse-steering-01/REUSE-DECISION.md#L60)).

**Acceptance and limits.** On a larger public synthetic corpus plus goal, require support and contrary passages or explicit abstention, corrected/rejected exact claims, separate plan approval, corrected bytes in fresh target exports, and representative baseline comparison. Inject an uncited edit, new contradictory revision, revoked source, forged snapshot, changed goal, and failed summary rebuild; each must deny stale approval/build/export, while a reviewed fresh snapshot recovers. Compare matched FTS5 and pinned Graphiti candidates against an independently fixed critical-evidence oracle. Reuse Graphiti 0.31.2’s episode/temporal/hybrid/Jev runtime through a bounded adapter; Elixir/SQLite own the manifest and decisions ([scale direction](../../../SCALABILITY_REUSE.md#L7)). Estimate 3–5 engineer-days for origin contract and focused integration, plus 2–3 for adversarial verification; actual backend/model quality and million-file capacity remain unproved by the 51 offline tests ([scale limits](../../../SCALABILITY_REUSE.md#L28)).
