# Graphiti episodes: revision-pinned extraction and temporal evidence

**Observed gap.** Company analysis still admits 2–4 whole sources and at most 32,768 body bytes; the extra passages visible in iteration 12 do not enter its model origin ([frozen analysis](../../../../tmp/enhancement-program/13/source-before/lib/harness_forge/company/analysis.ex#L169-L211); [handoff](../../12/handoff-to-13.md)). Graphiti's `add_episode` already extracts and resolves nodes/edges, generates embeddings, and invalidates conflicting edges. It also reads prior episodes as extraction context, then returns the episode plus nodes and edges ([pinned `graphiti.py`](../../../../../research/harnessforge-graph-rag-study-2026-11-02/sources/graphiti/graphiti_core/graphiti.py#L1334-L1586)). Its episode records retain content, `created_at`, `valid_at` and edge IDs; entity edges retain supporting episode IDs and distinct `valid_at`, `invalid_at`, `expired_at`, and `reference_time` ([`nodes.py`](../../../../../research/harnessforge-graph-rag-study-2026-11-02/sources/graphiti/graphiti_core/nodes.py#L318-L350); [`edges.py`](../../../../../research/harnessforge-graph-rag-study-2026-11-02/sources/graphiti/graphiti_core/edges.py#L263-L291)). None is an exact UTF-8 citation or a human policy decision.

**Connected change.** In the larger authorised corpus plus saved-goal journey, Elixir should issue bounded, immutable passage envelopes to a Python worker: server-owned nonempty group scope, source/revision/body hash, byte window plus parent context, source status, capture time, documented event/effective time, chunker version and stage configuration. Persist an episode UUID ↔ envelope manifest and checkpoint each successfully indexed revision. A retry must compare the manifest and graph episode; a changed revision gets a new episode identity. This matters because supplied `uuid` causes `add_episode` to load the existing episode rather than replace its body ([`graphiti.py`](../../../../../research/harnessforge-graph-rag-study-2026-11-02/sources/graphiti/graphiti_core/graphiti.py#L1450-L1460)). Bound prior-episode context and record **every** prior episode and summary that influenced extraction as uncited/transitive dependencies. Do not infer company chronology from capture order or saga `NEXT_EPISODE`; bulk saga links are sorted by `valid_at`, while `created_at` records ingestion ([`graphiti.py`](../../../../../research/harnessforge-graph-rag-study-2026-11-02/sources/graphiti/graphiti_core/graphiti.py#L1790-L1836)). Graphiti normalises future-tense edge dates to the statement reference time; application metadata must separately retain the planned date and distinguish source assertion from approved policy ([`temporal_edge_utils.py`](../../../../../research/harnessforge-graph-rag-study-2026-11-02/sources/graphiti/graphiti_core/utils/maintenance/temporal_edge_utils.py#L39-L96)).

**Reuse and acceptance.** Reuse pinned Graphiti 0.31.2 extraction, temporal resolution, `JevClient` node/edge dedupe and model routes, with Elixir/SQLite/FTS5 as authority ([reuse decision](../../../../tmp/enhancement-program/11/scale-reuse-steering-01/REUSE-DECISION.md)). From the same larger public corpus and goal, compare FTS and Graphiti-backed passage retrieval against independently fixed support/contrary/outdated/unknown oracles. Verify exact parent-span citations, explicit abstention, a corrected/rejected claim, separate plan approval, corrected actual export bytes and representative baseline comparison. Negative cases: reused UUID with changed body, undated proposal treated as adopted policy, foreign scope, new contradiction, revoked source and uncited prior context must fail eligibility. On worker crash or failed removal-summary rebuild, resume from checkpoints while derivatives remain denied; upstream restores an old summary on rebuild failure ([`graphiti.py`](../../../../../research/harnessforge-graph-rag-study-2026-11-02/sources/graphiti/graphiti_core/graphiti.py#L2174-L2250)).

**Trade-off and limit.** Estimated 3–5 engineering days for this adapter and integration checks after the selected backend and model controls are agreed. Start with FTS-only evidence if a consented generative model/backend is unavailable; mark Graphiti semantic extraction unavailable. The 51 offline spike passes establish source composition only, not installed backend, semantic accuracy or physical million-file throughput ([spike summary](../../../../../research/harnessforge-graph-rag-study-2026-11-02/reuse-spike/evidence/summary.json)).
