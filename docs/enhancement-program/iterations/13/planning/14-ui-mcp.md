# Connected corpus review and own MCP consistency

## Observed gap

The inspector selects a captured connection, project and goal, shows 25 body-free rows per page, and opens a 4,096-byte passage. Its preview does not feed analysis; the form still asks for 2–4 whole sources. Search requires invented contrary terms and clears the report. Thus a discovered exception may never enter the recommendation's origin ([corpus review UI, lines 25–42, 98–140](../../../../../tmp/enhancement-program/13/source-before/lib/harness_forge_web/components/company/corpus_review.ex); [analysis UI, lines 195–200, 241–286](../../../../../tmp/enhancement-program/13/source-before/lib/harness_forge_web/components/company/analysis.ex); [LiveView, lines 146–152](../../../../../tmp/enhancement-program/13/source-before/lib/harness_forge_web/live/corpus_review_live.ex)). Lower-pane visual inspection remains P2 partial, report reopening P3, and 496-query mounts an observed risk ([handoff](../../12/handoff-to-13.md)).

## Connected change and interfaces

Make the existing three-selector scope the entry to a **server-owned analysis run** over authorised corpus membership and one saved goal. Show captured/indexed/failed/skipped counts, checkpoint, stale generation, coverage by source family/time/status, and unknowns. A bounded page groups **supporting, contrary, outdated, unknown** passages; rows show source status/date, exact revision/hash/byte range, parent-context warning and an “open passage” action using the lazy inspector. Keep the evidence panel visible while correcting or rejecting a recommendation. Labeled steps lead to exact claim approval, separate plan approval, build, target-file inspection and representative evaluation. Missing critical coverage, incomplete scan or stale origin shows **abstain / refresh required**. The interface consumes bounded metadata and an immutable origin ID; it cannot mint membership, consent, citations or approval. Freshness includes cited, uncited, transitive and newly added contrary influences ([study, lines 157–176](../../../../../tmp/enhancement-program/11/scale-reuse-steering-01/STUDY.md)).

Extend own MCP with a read-only, bounded `harnessforge_company_analysis` tool: exact run ID or paginated summaries, coverage/abstention/blocker, origin version/hash and next Portal action. Return no source text, full membership or graph records. Recheck scope/privacy/origin on every call; empty or foreign scope yields a safe error. Keep plan/package readiness observational and approval separate ([MCP tools, lines 1–7, 48–82, 200–215](../../../../../tmp/enhancement-program/13/source-before/lib/harness_forge/mcp/tools.ex)). Shared-bearer MCP has no proven per-client isolation ([security retro](../../12/retro/security.md)).

## Acceptance, risk and effort

On a larger public corpus, a goal yields support and contrary passages, partial coverage, correction/rejection, exact claim and plan approvals, corrected actual exports and baseline comparison. Verify keyboard and 320/390 CSS-pixel lower-pane review at 100/200% zoom; search preserves the run/report. Negative checks cover forged IDs, revocation, new contradictions, failed purge rebuild and incomplete scan; all block stale review/MCP readiness. Recovery resumes from checkpoint and explicitly refreshes without repinning approvals. Compare owner-frozen critical misses and comprehension/recovery with FTS. Reuse SQLite/FTS, inspector and approval/export path; Graphiti 0.31.2 remains a bounded retrieval dependency ([reuse decision](../../../../../tmp/enhancement-program/11/scale-reuse-steering-01/REUSE-DECISION.md)). Estimate 4–6 engineer-days integration plus 2–3 QA-days. A status-only MCP is cheaper but leaves manual synthesis; a graph dashboard adds cost without improving review. Scripted responses and 51 offline tests prove neither semantic quality nor million-file operation.
