# Proposal 10 — explain what a static pass did

**Benefit.** An operator inspecting a static pass can tell that integrity was checked, no model-backed task ran, and runtime cleanup was never attempted. The next step is a qualified task evaluation.

**Evidence.** The [iteration03 UX review](../../03/review/ux-validation.md) observed a passed static evaluation whose summary led with “Recorded evaluation cleanup is incomplete” although cleanup was `not_started`. [Readiness](../../../../../lib/harness_forge/readiness.ex) retains that state and release refusal; [PackageReadiness](../../../../../lib/harness_forge_web/components/package_readiness.ex) prioritizes cleanup in its announcement. The [amendment](../../03/decision-amendment.md) requires OpenCode current task identities, applicability and admission to remain **Not assessed** without a live check. The five [retrospectives](../../03/retro/) repeatedly identify static-message confusion. Export recovery is a separate gap ([proposal 02](02-export-recovery.md)).

**Decision.** Change inspector presentation for a selected, completed `static_integrity` pass with `cleanup_status: not_started`. Lead with “Static check passed; no model-backed task or task cleanup was attempted. A qualified task evaluation is required for release review.” Keep seven stages, recorded cleanup, exact release refusal, selected identity and existing action visible. Explain that “not started” describes absent task execution. Exclude smoke, pending, failed and malformed runs.

**Acceptance.** A persisted static pass shows the contextual summary with unchanged states/gate reasons. A passed smoke retains its recorded `cleanup_status: complete` and existing summary. A task with `cleanup_failed` retains its warning; a `model_not_selected` task remains blocked with applicability/admission **Not assessed**. Unknown cleanup metadata gives no completion claim. Selection changes, reset, lock and revoked eligibility clear stale copy. Focused LiveView tests cover the contrast; native keyboard reading order at 320 CSS pixels and actual 200% zoom confirms discoverability.

**Alternatives and cost.** Export recovery fixes a failed action but touches form state and filesystem retry; defer separately. Marking static cleanup complete would misstate history. Files: `lib/harness_forge_web/components/package_readiness.ex` and focused test. Estimate: half to one engineer day including native review. Risk: optimistic wording could imply qualification; name the missing task and preserve release refusal.
