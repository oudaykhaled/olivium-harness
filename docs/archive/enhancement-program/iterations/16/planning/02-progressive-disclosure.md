# Iteration 16 planning: disclose the bounded manual path

**User and job.** A company owner with an authorised corpus and saved goal needs to reach a reviewed claim and separate plan without treating manual document assignment as a prerequisite. Success is four of five first-time operators identifying the corpus action unaided. Belief that zero manual assignments block corpus analysis falsifies the hypothesis. This is proposed, not observed novice evidence.

**Observed problem.** Company already offers a primary corpus button ([company_panel.ex, 1321–1342](../../../../../../tmp/enhancement-program/16/source-safe/lib/harness_forge_web/components/company_panel.ex)). Its guide says corpus claims need no legacy assignments ([guide.ex, 110–118, 177–184](../../../../../../tmp/enhancement-program/16/source-safe/lib/harness_forge_web/components/company/guide.ex)). Yet the visible scope line counts “assigned current captured sources,” while the older form instructs “choose 2–4” and says unchecked sources are excluded ([guide.ex, 328–348](../../../../../../tmp/enhancement-program/16/source-safe/lib/harness_forge_web/components/company/guide.ex); [analysis.ex, 195–199, 241–285](../../../../../../tmp/enhancement-program/16/source-safe/lib/harness_forge_web/components/company/analysis.ex)). The usability retrospective labels prerequisite confusion a hypothesis; the actual public journey used zero manual assignments ([handoff, 25, 40](../../15/handoff-to-16.md)).

**Options and decision.** Option A reuses the Company guide and analysis disclosure: keep the corpus action prominent; label the 2–4-source form “Manual analysis of selected sources” inside a collapsed, keyboard-operable disclosure; localize its checked-source warning; and clarify that assigned-source count describes legacy context, not corpus readiness. Existing users take one extra action. Option B adds an inline corpus/manual mode switch. It distinguishes paths but adds state and recovery risk across drafts and scope changes. Recommend A. Use native `<details>/<summary>` where suitable. Optional hashes, revision IDs and provider attribution may stay expandable, but exact excerpts, contrary evidence, uncertainty and separate decisions must remain visible before approval.

**Acceptance and Root verification.** Given a valid corpus, project and saved goal with zero manual assignments, when Company opens, then the corpus action is operable without opening manual analysis. Given closed manual disclosure, when a keyboard user opens it and selects 2–4 current sources, then the draft and source-specific coverage warning remain available. Given unavailable or changed scope, when the owner returns, then neither path reuses stale selections or implies completeness; the next action is explicit. Root should exercise these states at desktop and 390×844, including keyboard focus and screen-reader names; record novice outcomes separately if available. UI copy cannot imply policy authority, semantic coverage, approval, export enforcement or task success.
