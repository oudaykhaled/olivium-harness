# Planner 14 — minimal reuse and ownership

**Candidate, unselected:** Show a current source name, pinned capture date and permitted link beside each reopened finding's exact ID, revision and byte span. This helps the owner recognize supporting history before a separate Evidence decision; it proves neither semantic correctness nor coverage.

**Reuse and boundary.** `Company.Analysis.report/1` renders immutable IDs/spans in Company and Evidence. Selection already presents title, capture date and `source_url/1`'s HTTP(S)/host/userinfo check. Pass loaded `@sources` into both report call sites (`components/company/analysis.ex:341`; `live/portal_live.ex:1661`). Resolve display metadata only when source ID, latest revision ID **and body hash** match pinned context. Label `Source.title` as **current source name (may have changed)**, never capture-time title; date/URL belong to the matching pinned revision. Keep report/pins untouched. Links retain `noopener noreferrer`; opening one causes no selection, inference or decision. Owner files: report component, one LiveView call site and focused existing UI test. No schema, data-access or approval change.

**Fallback trade-off.** `Evidence.list_sources/0` and `get_source/1` expose latest-only metadata. For changed, purged or unavailable captures, retain exact IDs/span and say “Pinned capture details unavailable”; omit title/date/link. A historical-read API could recover old metadata, but adds privacy, revocation and query contracts. Defer it until needed.

**Acceptance/falsifier.** Matching capture shows clearly qualified current name, pinned date and safe link; missing or unsafe URL is explicit and unlinked. A newer capture never supplies an old report's date/URL/name. At 320/390 px and actual 200% zoom, metadata wraps and links remain keyboard reachable. Reopening, link use, reset and late events preserve report bytes, dirty guidance, pins and separate approvals. Misattribution or implicit authority mutation fails.

Stale-build recovery spans error classification, navigation/focus and reset (`portal_live.ex:1373,1430`); Guide discovery (`guide.ex:5–12,168–173`) does not help inspect a pinned finding. Preserve iteration08 outcome/coherence/portable-authority/approval-timing dissent and iteration09's synthetic-versus-real-model limit.
