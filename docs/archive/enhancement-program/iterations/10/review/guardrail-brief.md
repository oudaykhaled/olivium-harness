3. **[ADR10 contract4; analysis.ex:537–550] One bounded URL policy for selector AND report.** Replace/factor the current permissive `URI.parse` predicate within the component. Require explicit `http://` or `https://` authority (scheme case may be normalized only for comparison), nonempty syntactically valid host, nil userinfo, and a successful parse without exceptions. No DNS/network call. Explicit port must contain digits and be 1–65535; reject empty, signed, nonnumeric or out-of-range port. Absent port is valid. Reject percent-encoded C0/DEL controls or backslash; ordinary well-formed escapes in path/query/fragment may remain encoded. Preserve accepted URL bytes. All refusals return nil/no anchor with “Source link unavailable”, never raw unsafe text in HTML/attributes/errors.
