# Browser acceptance oracle: selected-goal coverage at approval

**Recommend one 09 functionality benefit:** a plan owner cannot approve a revision while any selected goal lacks a milestone with nonblank acceptance and evaluation text. Milestones default to `[]` (`lib/harness_forge/company/validation.ex:37,79`); approval checks freshness and eligibility, but no goal coverage (`lib/harness_forge/company.ex:110,340`). Review exposes revision, goals, milestones and decision (`lib/harness_forge_web/components/company/plan.ex:558,587,590,611`). A domain test approves an empty-milestone plan (`test/harness_forge/company_test.exs:400`). This checks declared accounting, not real policy completeness.

**Browser contract.** In an authenticated local workspace, use accessible labels/roles and stable IDs. Prepare two goals; save a plan whose milestone covers only A. Review both goals and hash; activate “Record exact plan decision.” Expect an alert naming uncovered B, focus on alert/review, retained plan/hash and proposed status, and a correction path. Domain oracle: zero decision/audit rows and artifacts. Cover B in a *new* revision, review its hash, explicitly approve; expect one decision/audit. Existing `test/harness_forge_web/company_builder_test.exs:149` covers stale-hash refusal, not browser focus/recovery.

**Negative/edge:** duplicate A milestones cannot hide B; stale/superseded revision refuses; approved ancestors stay immutable; rejection and zero-goal behavior remain explicit. Revoked claims still fail eligibility; coverage cannot override that gate. Package composition/build cannot begin from a refused plan (`lib/harness_forge/company.ex:138`).

Root should capture actual browser keyboard/AX evidence, pre/post domain counts and revision IDs. No browser/HTTP launched here. Ownership: Company eligibility/domain tests to one engineer; CompanyPanel/Plan error, focus and browser test to another. Estimate 0.5–1 day plus root verification. **Falsifier:** uncovered revision approves, writes audit/artifact, loses recovery context, or visibly refuses while domain accepts.
