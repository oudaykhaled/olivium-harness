# Dispatch controls: consent and budget at every provider attempt

**Observed gap.** HarnessForge has one workspace model setting and fingerprint; cloud consent holds at most 100 source IDs. Requests allow ≤131,072 prompt bytes, ≤4,096 output tokens and ≤60 seconds. Its ledger reserves before dispatch and retains uncertain reservations, but larger corpora and Graphiti's indirect stages cannot fit that singleton/array contract ([configuration.ex:7–35](../../../../../../tmp/enhancement-program/13/source-before/lib/harness_forge/models/configuration.ex#L7), [configuration.ex:102–150](../../../../../../tmp/enhancement-program/13/source-before/lib/harness_forge/models/configuration.ex#L102), [models.ex:89–116](../../../../../../tmp/enhancement-program/13/source-before/lib/harness_forge/models.ex#L89), [models.ex:204–225](../../../../../../tmp/enhancement-program/13/source-before/lib/harness_forge/models.ex#L204), [ledger.ex:44–125](../../../../../../tmp/enhancement-program/13/source-before/lib/harness_forge/models/ledger.ex#L44)). Graphiti Jev defaults to 120 seconds and five attempts; split/shrink can create further HTTP posts, and token tracking adds only successful-response usage ([jev_client.py:88–120](../../../../../../research/harnessforge-graph-rag-study-2026-11-02/sources/graphiti/graphiti_core/llm_client/jev_client.py#L88), [jev_client.py:203–284](../../../../../../research/harnessforge-graph-rag-study-2026-11-02/sources/graphiti/graphiti_core/llm_client/jev_client.py#L203)).

**Connected change.** Select a larger authorised corpus and saved goal, then persist a server-owned, versioned closure for each bounded passage/synthesis operation: scope, revision/hash, cited, uncited and transitive influences. A stage pin binds purpose, provider, endpoint, exact model ID, credential reference, prompt/schema version, consent revision, rate estimate and run limits. Elixir admits one attempt at a time: recheck nonempty permitted scope and every dependency's current consent/category; atomically reserve requests, tokens and cost; mint an attempt ID; allow one egress. The worker returns attempt ID, usage or unknown, output digest, error class and dependency/config pin. Revalidate generations, consent and pins before accepting results. Preserve current byte/token limits and ≤60-second HTTP timeout with checkpointed jobs. Set Jev `max_retries=1` and inject a metered `httpx.AsyncClient` so *each* `_post`, including split/shrink, crosses admission. Meter Graphiti's other model, embedding and reranking clients equivalently; deny unwrapped egress. Orchestration owns bounded retry/backoff, deadlines and cancellation. Ambiguous dispatch retains its full reservation; another attempt requires a fresh reservation and remaining budget. External billing is not exactly once ([ledger.ex:128–184](../../../../../../tmp/enhancement-program/13/source-before/lib/harness_forge/models/ledger.ex#L128), [STUDY.md:197](../../../../../../tmp/enhancement-program/11/scale-reuse-steering-01/STUDY.md#L197), [STUDY.md:328](../../../../../../tmp/enhancement-program/11/scale-reuse-steering-01/STUDY.md#L328)).

**Reuse and acceptance.** Compose pinned Graphiti `LLMRuntime`, `LLMTransport`, `PromptRoutes` and its JevClient for node/edge dedupe; extraction and summaries require a separately supplied generative model ([llm_runtime.py:147–193](../../../../../../research/harnessforge-graph-rag-study-2026-11-02/sources/graphiti/graphiti_core/llm_client/llm_runtime.py#L147), [SCALABILITY_REUSE.md:7–11](../../../SCALABILITY_REUSE.md#L7)). Positive: a larger synthetic corpus plus goal yields support/contrary/unknown or abstention, an exact human correction/rejection and separate approvals, corrected target bytes and representative evaluation, with every actual attempt metered. Negative/recovery: revoked or uncited source, changed stage pin, empty scope, timeout, cancellation, exhausted budget, malformed output or failed removal-summary rebuild blocks dispatch or serving; restart preserves uncertain charges and tombstones. Compare frozen FTS5 and candidate critical-evidence oracles and report missing model/backend proof ([handoff-to-13.md:63–73](../../12/handoff-to-13.md#L63)).

**Trade-off and effort.** A per-attempt gateway adds durable writes and worker instrumentation (estimate 3–5 engineer-days plus 2 QA days), but prevents silent spend/consent escape. Leaving native Jev retries enabled is cheaper initially and loses attempt-level accountability. No paid pilot or model-quality claim follows from the 51 offline fixture passes ([SCALABILITY_REUSE.md:28–32](../../../SCALABILITY_REUSE.md#L28)).
