# Bounded resumable physical capture

**Observed gap.** The local importer walks the entire approved tree into a path list, rejects the 501st eligible file, reads all bodies before one transaction, and rejects aggregate bodies above 16 MiB. One unreadable file aborts the import; the complete-list deletion pass runs only after every document persists. The separate remote sync already commits a page with a cursor and an explicit complete flag, but local sync delegates to the all-or-nothing importer. These contracts prevent a physical corpus beyond one batch from becoming a reliable input to analysis ([local_import.ex:21–41,54–85,90–101](../../../../../../tmp/enhancement-program/13/source-before/lib/harness_forge/evidence/local_import.ex); [evidence.ex:76–109,126–190,591–609](../../../../../../tmp/enhancement-program/13/source-before/lib/harness_forge/evidence.ex)). Iteration 12's 5,000 captured records are not physical-file or resume proof ([handoff-to-13.md:39](../../12/handoff-to-13.md)).

**Connected change.** Add a durable local capture run with an approved root identity, monotonic scan generation, bounded work queue, and persisted enumeration checkpoint. Process a small fixed batch at a time under existing 1 MiB per-file and 16 MiB per-batch limits; no whole-tree path/body list or corpus-wide transaction. Each file yields `captured`, `unchanged`, `excluded`, `failed`, or `stale` with relative path, observed file identity, content hash/revision when read, reason, and retry state. Persist source revision, FTS update, per-file outcome, and downstream index/outbox intent atomically. A retry uses `(connection, relative path, content hash, parser version)` for computation reuse, while current source status and access are rechecked before publishing. Bound queued bytes/items and concurrent readers against SQLite write capacity; stop intake when the queue is full. Report discovered/eligible/captured/indexed/excluded/failed/stale counts and lag separately. A run is **complete** only after traversal, all eligible outcomes, and index settlement; partial scans retain incomplete coverage and cannot delete unseen sources. On restart, resume the committed checkpoint, revisit the boundary entry safely, and reconcile changed entries by hash. Only a fully completed generation may mark previously active unseen sources missing, in bounded pages.

This capture feeds a server-owned, paginated corpus membership and exact-byte passage retrieval; its completeness/lag enters the versioned origin so missing coverage can cause abstention. The same origin must carry cited, uncited and transitive inputs through human correction/rejection, exact claim and separate plan approval to actual corrected exports and representative evaluation ([SCALABILITY_REUSE.md:15–25](../../../SCALABILITY_REUSE.md); [PRODUCT_OUTCOME.md:27–31](../../../PRODUCT_OUTCOME.md)). Retain Elixir/SQLite authority and FTS baseline; pass only revision-pinned authorised passages to pinned Graphiti 0.31.2's existing episode path when a separately selected backend and model stages are available ([REUSE-DECISION.md:11–30](../../../../../../tmp/enhancement-program/11/scale-reuse-steering-01/REUSE-DECISION.md)).

**Acceptance and trade-off.** On public physical fixtures, capture >500 files across bounded commits, restart mid-tree without duplicate revisions, and show >100 corpus members with paged metadata; prove exact target export bytes after a cited correction. Inject unreadable/changed/symlink files, crash before and after commit, queue saturation, revoked scope and incomplete scans: each must preserve explicit outcomes, deny stale evidence, and avoid false deletion or approval. Compare FTS versus the candidate on a frozen support/contrary/missing oracle and representative tasks. Estimated 3–5 engineer-days for capture and integration, plus independent validation; checkpoint design and full-generation reconciliation increase state complexity. An initial batch-only extension is simpler but retains the whole-tree failure mode. No current evidence establishes physical million-file throughput, semantic quality, or installed Graphiti backend ([STUDY.md:81–88,305–328](../../../../../../tmp/enhancement-program/11/scale-reuse-steering-01/STUDY.md); [SCALABILITY_REUSE.md:27–32](../../../SCALABILITY_REUSE.md)).
