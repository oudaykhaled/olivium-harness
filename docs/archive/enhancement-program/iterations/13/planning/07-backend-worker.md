# Backend and bounded worker proposal

Source prefix **G** below means `../research/harnessforge-graph-rag-study-2026-11-02/sources/graphiti` from the HarnessForge repository.

**Observed gap.** Iteration 12 still admits only 2–4 whole analysis sources, despite bounded passage inspection; the required next outcome is a larger authorised corpus and saved goal carried through contrary-evidence review, exact claim and separate plan approval, corrected actual exports, and representative evaluation (`docs/enhancement-program/iterations/12/handoff-to-13.md:91–103`). Graphiti 0.31.2 is selected for graph construction/Jev routing, while its backend and product lifecycle remain unqualified (`tmp/enhancement-program/11/scale-reuse-steering-01/REUSE-DECISION.md:5–11,72–79`). The 51 offline passes used mocked providers and no backend (`../research/harnessforge-graph-rag-study-2026-11-02/reuse-spike/evidence/summary.json:7–12,29–33`).

**Selection and narrow contract.** Trial the pinned Graphiti source with its built-in **Neo4j driver** first, behind one local, supervised Python worker; make backend acceptance conditional on a separately pinned server distribution, license/notice review, and real persistence/search/removal tests. The core package already requires `neo4j>=5.26.0`; its adapter exposes connectivity checking, index creation, close and transactional commit/rollback (`G/pyproject.toml:11–21`; `G/graphiti_core/driver/neo4j_driver.py:65–98,148–158,186–230`). FalkorDB is a feasible *challenger*: its client is optional `>=1.1.2,<2`, but its adapter logs query parameter **values** on errors, and the generic fallback transaction executes immediately (`G/pyproject.toml:32–36`; `G/graphiti_core/driver/falkordb_driver.py:238–253`; `G/graphiti_core/driver/driver.py:145–166,213–220`). Require a logging fix or proven redaction before sensitive use. Kuzu is explicitly deprecated (`G/pyproject.toml:32–33`). The supplied Graphiti Apache-2.0 license does **not** establish either database server's license or deployment rights (`G/pyproject.toml:11`; `tmp/enhancement-program/11/scale-reuse-steering-01/REUSE-COMPARISON.md:13–25`).

Elixir owns a versioned job/outbox, nonempty server-derived scope, revision/hash/UTF-8 span and all cited/uncited/transitive dependencies. Send bounded `ingest(revision, passage_ids, idempotency_key, stage_config)`, `search(scope_token, query, limit, snapshot)`, `remove(episode_ids, fence_generation)` and `health` requests over a local authenticated channel; return typed IDs/status/attempt receipts, never authoritative citations or approvals. Elixir resolves returned IDs to current permitted passages, retains FTS5 as fallback/baseline, and alone admits reviewed guidance to exports (`docs/enhancement-program/SCALABILITY_REUSE.md:9–29`). The worker starts only with a locked Graphiti commit, resolved wheel/dependency hashes, backend image digest, notices and explicit endpoint allowlist. Set `GRAPHITI_TELEMETRY_ENABLED=false` **before import**: upstream defaults telemetry on and can post to PostHog (`G/graphiti_core/telemetry/telemetry.py:15–37,76–114`). Restrict outbound traffic to independently consented model endpoints and the local graph socket; no implicit provider fallback.

**Acceptance/recovery.** Demonstrate bounded checkpoint/resume after worker death; idempotent revision replay; persisted search after backend restart; empty/foreign scope refusal; invalid citation rejection; and source revocation fenced **before** graph removal, including failed summary rebuild. Timeout/cancellation must retain uncertain per-attempt spend and keep affected derivatives unservable. Freeze the same critical support/contrary oracle for FTS5 and Graphiti, then verify corrected bytes in actual target exports and representative tasks. If licensing, redaction or lifecycle gates fail, keep the connected FTS5 passage path available and mark graph enrichment unavailable; do not count the backend as installed or semantically qualified. Estimate: 3–5 engineer-days for the backend/worker seam and recovery proof, excluding corpus, UI and model-quality work.
