# Passage retrieval and measured FTS baseline

**Observed gap.** `Evidence.search/1` ranks document revisions, then calls `get_source/1` for up to 50 results; `source_dto/1` attaches the entire latest body. `Chat.Retrieval` likewise scores full bodies and cuts one excerpt per source, so its 24,576-byte prompt budget does not make candidate hydration bounded ([Evidence.search:250–278](../../../../../tmp/enhancement-program/13/source-before/lib/harness_forge/evidence.ex#L250), [source_dto:696–704](../../../../../tmp/enhancement-program/13/source-before/lib/harness_forge/evidence.ex#L696), [Chat.Retrieval:31–50,94–135](../../../../../tmp/enhancement-program/13/source-before/lib/harness_forge/chat/retrieval.ex#L31)). Iteration12’s inspector already enforces scope before FTS and a 26-ID page, with an exact 4,096-byte current-revision window, but explicitly says browsing does not establish analysis membership ([CorpusReview:1–5,530–565,671–705](../../../../../tmp/enhancement-program/13/source-before/lib/harness_forge/company/corpus_review.ex#L1); [handoff](../../12/handoff-to-13.md#delivered-seams-and-authority)).

**Connected change.** Add an Elixir-owned, revision-pinned passage index to SQLite FTS5, keyed to authorised corpus membership, source/revision/body hash, UTF-8 `[start,end)`, parent section/document identity, and parser/index generation. Keep an immutable parent context window and document status plus event/effective/capture dates; unknown fields stay unknown. Index exact captured bytes; any normalization must retain a verified offset map. Search first intersects a nonempty server-derived project/source scope, active eligibility and current revision, then ranks and fetches a fixed number of passage IDs. Read only bounded byte slices for final candidates; validate hash, UTF-8 boundaries, parent and scope again before packing. Never use the preview token as analysis authority. Define a bounded retrieval snapshot: saved goal and scope/generation, query variants, ranked candidate IDs, selected support/contrary/unknown passages, exclusions, truncated coverage, and cited **and uncited** prompt influences, including transitive graph/summary origins. Reserve contrary and unknown slots; if critical source families, chronology or coverage are missing, conduct one bounded follow-up query or abstain. Passage score conveys relevance, not adopted policy.

**Reuse and acceptance.** Reuse `CorpusReview`’s scope predicates and exact window checks, existing SQLite/FTS, and current citation/approval machinery. Graphiti 0.31.2 may contribute hybrid candidate IDs after a backend is selected; Elixir must remap every result to permitted current exact passages. Its empty `group_ids` becomes unfiltered `None`, so reject empty scope before any worker call ([pinned search.py:155–156](../../../../../../research/harnessforge-graph-rag-study-2026-11-02/sources/graphiti/graphiti_core/search/search.py#L155); [reuse decision](../../../../../tmp/enhancement-program/11/scale-reuse-steering-01/REUSE-DECISION.md)). Freeze a public heterogeneous corpus/questions and independent oracle **before** tuning: required supporting, contrary, outdated, critical and intentionally absent evidence with parent-context labels. Compare FTS and Graphiti candidate on identical eligible revisions, queries, passage/token caps and saved goal; report Recall@20/50 by critical/conflict/time slice, exact-byte/parent correctness, abstention, stale/irrelevant hits, latency and cost. A missed critical exception, wrong byte quote, foreign/revoked passage or unreported incomplete scope fails its cell. Revision change, new contrary source, cancellation or failed derivative rebuild must refuse stale analysis/approval/export until refreshed; preserve tombstone-first denial. Positive journey still requires human correction/rejection, exact claim and separate plan approvals, corrected **actual** target export bytes and representative baseline task assessment ([quality retrospective](../../12/retro/quality.md); [handoff](../../12/handoff-to-13.md#13-minimum-outcome-exact-design-unselected)).

**Trade-off and limit.** This is roughly 2–4 engineer-days for the passage seam plus 2–3 for the frozen oracle and integration checks, conditional on corpus membership/capture and origin-v2 ownership. A whole-document FTS reuse is cheaper but retains hydration and hides within-document conflicts; a graph-only index adds backend and exact-span risk. The 51 offline Graphiti passes and million *logical* repetitive probe do not establish installed backend, semantic quality or physical million-file throughput ([study:252–258](../../../../../tmp/enhancement-program/11/scale-reuse-steering-01/STUDY.md#L252); [spike summary](../../../../../../research/harnessforge-graph-rag-study-2026-11-02/reuse-spike/evidence/summary.json)).
