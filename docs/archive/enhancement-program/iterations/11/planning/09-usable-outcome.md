# Usable owner outcome after a reviewed company package

**Recommend:** let an owner record one *representative task assessment* against a chosen built package and saved goal. Guide ends at “Open packages and export” (`guide.ex:204–210`); Evaluations offers fixed checks, not company-specific judgment (`portal_live.ex:2397–2424`). Plan milestones hold evaluation prose but may have empty `goal_ids` (`validation.ex:89–103`), so a build or synthetic run cannot establish the owner’s outcome.

Add a discoverable “Assess representative task” action after an eligible build: task description, exact package digest, goal revision, owner-authored obligations/rubric revision, one result per obligation, critical violations, explicit judgment. Show source/goal/package identity and “Owner-reported assessment; runtime and release qualification unverified.” Permit a draft, then immutable acceptance only with all mandatory results, no critical violation, and exact current pins. Preserve predecessors across package, goal or rubric changes; successors need separate review. Do not alter trusted `Evaluation.Run` provenance or release eligibility. Coherent goal/milestone coverage remains a separate gate.

**Acceptance:** a synthetic authorised multi-source analysis with future goal, edited/rejected recommendation, exact Evidence and plan approvals, build, then representative task produces a labelled owner receipt and a keyboard-reachable Guide route to it. Omitted mandatory result, critical violation, foreign workspace, stale package/goal/rubric, interrupted submit or forged revision refuses accepted success without partial record. Returning from evidence/source links retains dirty draft and focus; deliberate departure requires save/discard, while reset/revocation clears sensitive mounted state and late events cannot revive it. At 320/390 CSS pixels and actual 200% zoom, labels, full obligation text, status and next action fit with visible focus and no horizontal clipping. Assessment never starts inference, approves claims/plans/releases, selects a replacement pin, or executes generated code.

Coherence-first goal/milestone coverage would prevent incomplete plans sooner; retain it for exact approval-time design. Public fixtures prove mechanics only; real company/model quality and productivity remain unmeasured.
