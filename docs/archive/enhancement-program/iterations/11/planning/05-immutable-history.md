Persist a bounded, immutable, workspace-scoped **owner assessment** for one task: task identity, exact artifact digest, plan ID/revision hash, goal IDs/content hashes, rubric revision, each mandatory obligation's result, critical violations, owner judgment and timestamp. Show captured package/goal/rubric/decision and successor beside separate current eligibility. A successor requires its own receipt; old bytes remain historical. Bound retained task evidence; define purge/backup/restore semantics. Restore may retain history but must quarantine authority and require new review (`privacy/snapshot.ex:7–8,270–350`).

**Acceptance:** Synthetic native Company journey analyses multiple documents/history plus a goal, edits/rejects guidance, exactly approves a successor and plan, builds/exports, then records one task receipt with complete results. Integration checks refuse successful/accepted judgment for missing obligations, unresolved critical violations, foreign workspace, forged plan/digest/goal/rubric pin, duplicate decision or interrupted task. Native and API checks show an old receipt unchanged after profile/project/source mutation, a new package and rubric successor, while current eligibility becomes stale; no automatic remap or approval. Purge removes dependent retained bytes; backup/restore retains only quarantined history. Own MCP, if exposed, returns the same workspace-scoped historical/current distinction and per-client authority.
