# 05 proposal: adversarial acceptance for goal-origin rule authority

**Choice and value.** Select one functionality unit: approve an exact rule derived from a selected company goal, then build/export honest goal provenance without inventing a citation. `Evidence.create_claim/1` requires citations (`lib/harness_forge/evidence.ex:288–314`); `Company.resolve/1` pins goals but validates cited claims (`company.ex:245–273`); `Harnesses.specification/3` emits `goal_id: nil` (`harnesses.ex:185–195`). The compiler accepts an explicit goal with empty evidence (`contracts.ex:299–319`). This improves traceable intent; the [04 handoff](../../04/handoff-to-05.md) leaves company fitness unproven.

**Adversarial contract.** A versioned, typed basis contains workspace-scoped goal ID and content hash; the immutable revision hash covers text and basis. A separate exact-revision decision and approved plan selecting that goal/revision grant admission. Recheck at plan approval, build, artifact eligibility and export. Goal selection, historical package identity and restored decisions grant nothing. Direct `Harnesses.build/1` must refuse goal-origin rules without the same approved plan binding. Preserve citation-origin hashes, package bytes and legacy verification.

**Acceptance attack set.** Prove propose → decide → plan → build → export with `goal_id`, empty evidence and matching provenance. At each gate reject missing/unknown basis version, mixed citations, malformed hash, foreign workspace, unselected goal, wrong goal hash, superseded/rejected claim, withdrawn approval and changed plan. Exercise direct build, export after withdrawal, source/workspace purge, restore quarantine and revocation before publication; refusal writes no new artifact/export bytes. An unrelated cited-only package stays eligible and byte-identical. Preserve exact approval and consent.

**Ownership and risk.** Root owns schema/migration, privacy fence and integration; Evidence/Decisions own basis/approval; Company owns plan admission; Harnesses owns mapping/rechecks; QA owns negative tests and reporter. Conflict admission needs declaration semantics and misses undeclared contradictions. Route identity crosses live Docker execution and [03's accepted abstention](../../03/decision-amendment.md). This choice follows operator value, reliability and scope, not proposal count.
