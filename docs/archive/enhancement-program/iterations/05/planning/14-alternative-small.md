# 05 proposal 14 — resolve the coding route once, fail closed

**Operator benefit.** A Docker query failure must not silently select a different model route before a company task. This prevents misleading profile identity and attempted execution. Company fitness and favorable read-only task admission remain unproven.

**Code evidence.** `Coding.transport/0` (`lib/harness_forge/execution/coding.ex:427`) maps every result except exact `Docker Desktop\n` to `unix_socket_proxy`, including failure and malformed output. `profile/0` calls it three times (lines 35–38); `run/2`, proxy creation and verification resolve it again (lines 130, 446, 661). The accepted [03 amendment](../../03/decision-amendment.md) documents Docker-backed profile discovery timing out read-only inspection; task identity and admission remain **Not assessed** there.

**Decision (bounded ADR).** Return an explicit route-discovery result and pass one validated route through one coding run's profile, proxy creation and verification. Recognize Desktop and a documented Unix-host response; error, timeout, blank or unknown output refuses before starting. Record the selected route with existing profile identity. Readiness remains command-free. `Coding` and direct tests belong to a principal backend owner; root owns integration and board. Target one PR under 400 net lines.

**Acceptance.** Controlled Desktop and Unix responses yield distinct consistent profiles/proxy choices from one discovery; unknown/error responses refuse with a stable reason and create no run resources. A route change between runs changes profile identity. Read-only Inspect/Refresh makes zero Docker/port calls and retains task abstention. Exercise failure cleanup and Docker tests when available; preserve immutable artifact bytes, approvals, consent, purge/restore and export gates. Blast radius: coding execution/profile identity. Rollback reverts code and refuses mismatched historical runs.

**Alternatives.** Goal-origin authority gives more direct policy coverage but needs a new immutable basis, decision and purge contract across Evidence/Company/Compiler. Declared-conflict admission needs a declaration/resolution lifecycle and exact revision invalidation. Both are valuable separate iterations. A pure current-identity cache is broader and risks treating historical route data as current authority; the 03 abstention remains binding.
