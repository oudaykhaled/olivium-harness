Existing local authorization covers implementation and synthetic verification; no additional owner approval is needed. This credential is deliberately independent of browser logout/session epoch; document stop, replace/unset configuration, and restart as the revocation procedure. The safe integration is an **exact `/mcp` branch** to a dedicated plug that authenticates, checks peer/Host/Origin and handles raw bytes; every other path continues through the existing guard unchanged. Root owns that shared integration. No prefix/path-normalization bypass.
- Do not expose source bodies, full plan snapshots, claim text/citations, connector credential references/values, workspace filesystem paths, tokens or cookie material in this first readiness slice. A wider content surface requires a separately selected scope and its consent/minimization contract.
