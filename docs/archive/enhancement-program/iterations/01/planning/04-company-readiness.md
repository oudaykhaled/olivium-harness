# Proposal: company harness readiness preflight

**Priority: high.** A user can fill in a company profile, catalogue, project, evidence, goals and plan, yet discover the next blocking condition only after submitting a form or attempting a build. `Company.create_plan/1` resolves profile, project membership, approved exact claims and scoped sources at submission ([company.ex:71–77](../../../../../../lib/harness_forge/company.ex#L71-L77), [company.ex:234–263](../../../../../../lib/harness_forge/company.ex#L234-L263)); `Company.build_inputs/1` admits only an approved, still eligible snapshot ([company.ex:138–169](../../../../../../lib/harness_forge/company.ex#L138-L169), [company.ex:318–335](../../../../../../lib/harness_forge/company.ex#L318-L335)). The company UI currently offers a general empty-claims note and status-based build button; most failures appear as event errors, including one generic catch-all ([company/plan.ex:50–53](../../../../../../lib/harness_forge_web/components/company/plan.ex#L50-L53), [company/plan.ex:256–299](../../../../../../lib/harness_forge_web/components/company/plan.ex#L256-L299), [company_panel.ex:483–520](../../../../../../lib/harness_forge_web/components/company_panel.ex#L483-L520)).

**User benefit.** Show an ordered, current checklist in the Company panel: company profile; repository and project membership; assigned active sources; exact approved claims; optional goals; immutable plan decision; current plan snapshot; package build; evaluation; release. Each item says **ready**, **action needed** or **unavailable**, names the affected record, and links to the existing screen/action. The final summary distinguishes “ready to propose,” “ready to build,” “package built,” and “eligible for release.” A built package is never described as runtime qualified: task execution capability is separately reported by `Evaluations.capabilities/0` ([evaluations.ex:15–34](../../../../../../lib/harness_forge/evaluations.ex#L15-L34)), and release approval requires a passed, qualified task evaluation with matching identities and complete cleanup ([releases/validation.ex:8–49](../../../../../../lib/harness_forge/releases/validation.ex#L8-L49)).

**Smallest functional slice.** Add a read-only `Company.readiness(plan_id)` (where `nil` means no plan), returning string-keyed JSON-compatible data with `stage`, `checks` (each containing `id`, `status`, `reason` and `action`), and `checked_at`. With no plan, inspect current profile/catalogue/project and scoped approved-claim availability. For a proposed plan, report the missing decision and current snapshot status; for an approved plan, reuse `build_inputs/1`. Once an artifact exists, use `Harnesses.eligible/1` to report its current export eligibility. Avoid creating plans, approvals, artifacts or evaluations. Integrate the report into the Company panel reload and after relevant local changes. Keep it advisory and recompute at submission: `Harnesses.build_plan/2` already checks the exact revision and current inputs before publication ([harnesses.ex:8–24](../../../../../../lib/harness_forge/harnesses.ex#L8-L24), [harnesses.ex:70–90](../../../../../../lib/harness_forge/harnesses.ex#L70-L90)). Avoid exposing source bodies or credentials; display only short human-readable reasons and opaque IDs.

**Acceptance.** A fresh workspace shows profile/project/evidence setup actions; an approved scoped plan shows build-ready; changing assigned catalogue data, withdrawing a source, superseding a selected claim, or rejecting a plan changes the relevant check to action needed on reload; an approved predecessor stays eligible when only a successor exists. After a synthetic build, static integrity may read as passed while release remains blocked by unqualified or unavailable managed task execution. An unavailable runtime is explicitly unavailable, with no fallback. The preflight never grants authority, never runs repository/model-generated code, and cannot bypass existing plan, export or release gates. Test the report's state transitions and one LiveView rendering path with public synthetic fixtures; do not count this as live company or model qualification.
