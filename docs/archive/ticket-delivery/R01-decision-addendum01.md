# R01 decision addendum 01

**Public contract.** `Evidence.revision_restriction_status(event_id,caller)` and `Evidence.resume_revision_cleanup(event_id,expected_version,caller)` return `{:ok,receipt}` or `{:error,code}`. Receipt is decision01’s exact envelope plus `cleanup_version` (checkpoint `lock_version`, initially 0); `cleanup_state` is `pending|completed`. Both authenticate and resolve workspace server-side; unknown/foreign events return `not_found`. Resume requires nonnegative integer version, existing privacy-before-SQL ordering and writability. Equal version executes at most 100 corpora, atomically advancing checkpoint/version; older versions return current receipt without work; future versions return `version_conflict`. Completed resumes are inert. Restrict replay reauthenticates, compares canonical request digest and returns the same event with current checkpoint. WEB supplies no cursor or policy state.

**Central denial.** In `Corpora.invalidate_source_page`, consult Evidence’s source-hold predicate before the active-source branch: held members become `denied`, passage reference clears; advance authorization generation. `assert_current` rejects an indexed EXISTS joining holds to matching workspace/source/revision/hash memberships with status `active` **or** `denied`. Removed memberships require existing generation advancement; old certificates remain stale. All boundary adapters reuse Evidence predicates.

**Identity.** Any hold for `(workspace_id,source_id)` blocks every upsert/recapture of that existing connection/provider/external-ID identity, including identical bytes, changed metadata and new bodies. No restore/replacement revision is supported. Different connection/tenant identities retain independent existing authorization; never merge by hash. Test each case.

**Restore/rollback.** Snapshot quarantine atomically remaps both tables’ workspace, preserves holds/checkpoints/IDs and reinstates immutable triggers; existing grant withdrawal remains. Missing legacy tables confer no grants. Migration down rejects any hold/checkpoint rows. Test restored denial and rollback refusal; no silent authority revival.
