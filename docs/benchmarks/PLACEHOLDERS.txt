Path placeholders in docs/benchmarks

Some files in this folder were written on the machine that ran the benchmarks
and contained absolute paths from it. Those path prefixes are replaced with
placeholders. Nothing else in these files is changed.

Placeholders
  the benchmark output folder in the home directory  ->  <bench-out>
  the API key file                                   ->  <key-file>
  the project checkout folder                        ->  <repo>
  the tooling scratch folder                         ->  <scratch>
  a temporary folder under the system tmp folder     ->  <tmp>
  the file owner column of ls -l output              ->  <user>

Recorded SHA-256 values that were updated

Some files record the SHA-256 of other files in this folder. Where a recorded
file was changed by the replacement, the record now holds the new digest.
The value recorded when the run was written is kept here.
