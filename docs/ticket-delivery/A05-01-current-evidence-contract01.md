# A05-01 current EvidenceBundle decision 01

**Decision:** implement a bounded current-FTS inspection contract over Retrieval, not full A05-01/R01 acceptance. Root must consume this decision before releasing one principal author. Accepted scout/guardrail receipts establish the reuse baseline; this review checked the relevant producer, caller, cursor, provenance and analysis seams directly. Exact interfaces and read scopes/hashes are in decision01.json.

## Contract and persistence

Add Retrieval.retrieve_evidence/2, read_evidence_summary/3, read_evidence/4 and open_evidence_passage/4. One EvidenceBundle module supplies strict request normalization and deterministic projection; it cannot authorize or search. Retrieval owns every guarded database/Passages operation. Results use string-keyed maps and existing error tuples.

RetrievalRequest.v1 requires corpus_id, project_id, goal_id, goal_hash, expected_generation and question. Optional version, mode, time_mode and purpose default to RetrievalRequest.v1, fts, current and inspection; optional declaration_ref retains the exact existing id/digest shape. Reject unknown keys, atoms, invalid types and other enum values before search. expected_generation is a CAS expectation, never authority. No caller-supplied scope, principal, policy, generation, snapshot, history handle or timestamp is admitted. Inspection names the existing checked operation; it does not assert a new positive-purpose grant. Other purposes are unsupported. Hold absence grants nothing.

Refactor the existing producer internally so the legacy retrieve/2 path still writes its exact v2 envelope. Only retrieve_evidence/2 writes version3: the identical envelope plus evidence={request_digest,caller_digest}, two SHA256 strings. Version3 fixes the current/fts/inspection contract; scope comes from existing immutable pins. Existing JSON column and state CHECK suffice: no migration/backfill. Preserve the 16384-byte envelope limit, all packing limits and the existing envelope+coverage digest algorithm. The extra evidence object costs exactly 180 canonical JSON bytes; 2→3 adds none. Measure the final canonical envelope. Oversize fails before insertion; never truncate. Request identity is Contracts.digest of the normalized request; caller_digest hashes the existing workspace/session tuple. Binding identity hashes those two digests, existing scope pins and fixed contract/version/purpose/time/admission labels. No positive principal registry is invented.

## Projection and identity

EvidenceBundle.v1 exposes legacy run_id/digest/state, request and binding digests, snapshot_digest=stored run digest, scope, current time mode, inspection purpose, admission basis, known semantic/authorization generations, null index/purpose-policy generations, stored index versions, coverage, selected citation identities and structured reasons/unavailable capabilities. Hashes use Contracts; index versions never masquerade as a generation. Separate deterministic bundle core from page rows, display metadata and expiring tokens. Exclude run UUID/time from bundle_digest; equivalence is guaranteed for the same explicit snapshot/context, not independently rerun retrievals. citation_digest hashes workspace plus the ten existing exact identity fields, including source/revision/body/snippet/parent hashes and half-open UTF-8 spans.

DTO status is ready only for stored ready, partial only for stored abstained with selected_count>0, otherwise abstained. Preserve legacy.state and define analysis_ready solely from the stored ready gate. Missing historical facts remain null/unknown. Expose acquisition_by_kind=null with history status unknown, not a fabricated empty history or inferred kinds. Global capture/index counts remain their original scope; traversal cannot establish replay eligibility. Graph and historical capabilities are unavailable. Full per-kind history acceptance remains open.

## Reads, cursors and adoption

All new reads require a checked version3 run and matching live caller digest; legacy v1/v2 return legacy_contract_unavailable through new APIs and retain their old APIs unchanged. Summary is metadata-only. Page/open reuse checked_run, membership and Passages verification under Corpora.guard; no plain supplied DTO is trusted. Cursor binding includes contract kind, run ID/digest, request/binding digests, snapshot digest, purpose and time mode plus existing session signing/600-second expiry. Reject old/mismatched cursors; never restart pagination silently.

Root wires existing WEB FTS submit/read/page/open to the new APIs with compatibility-shaped existing result fields and an additive evidence_bundle field. Existing saved legacy runs and graph paths retain legacy calls. No endpoint, new UI workflow or machine caller adapter. Internal callers invoke the same APIs; future MCP contract fixtures use the same genuine operator fixture, expressly not machine authorization. resolve_for_analysis reuses the same status projection for new runs while retaining its stored-ready gate, hydration, manifest and OriginV2/AnalysisV2 path. Bundle readiness authorizes neither dispatch nor claims.

## Acceptance and ownership

One principal owns retrieval.ex and new company/evidence_bundle.ex. Root exclusively owns WEB integration, contract tests and shared integration; no other source files needed. Root verifies deterministic cross-adapter identities, unchanged legacy digests/reads, malformed/forged inputs before search, empty/foreign scope, revocation/publication/open/dispatch fences, cursor changes, UTF-8 tamper, unknown history and no partial promotion. Preserve exact claim decisions, separate plan approval, transitive consent, budget/cancel controls and unknown-outcome handling. Run focused then canonical tests; this decision executed none.

Keep Graphiti0.31.2 pin and SQLite/FTS. No transport, provider, historical, physical-scale, model usefulness or installed qualification is claimed. Rollback is code-only for this additive path: old readers can still verify immutable v3 bytes; no row rewrite or schema rollback.
