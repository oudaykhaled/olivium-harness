# Olivium Harness design contract (dark theme v1)

Purpose: the one source the styles, brand and assets lanes follow without talking to each other; re-implemented from the Olivium Harness website reference (tokens, type, shapes, idioms), never pasted from it. Principle for the styles lane: **this is a re-skin, not a re-layout** — layout properties (display, grid, flex, widths, paddings, margins, min-heights, overflow) and every media query stay; visual properties (colour, background, border, radius, shadow, font, letter-spacing, transition) change. Identifiers never change (see §10).

## 3. Shape, focus, motion

- Radius 0 everywhere (`button, input, textarea, select`, `.pill`, `.nav-item`, `.nav-count`, `.panel`, `.claim-card`, `.notice`, `.form-error`, `.chat-question`, `.metrics`, `.empty-state`, `.empty-icon`, `.workspace-switch`, `.workspace-avatar`, `--company-radius: 0`, `.harness-stage-symbol`). Only `.operator-avatar` stays 50%. Status/live dots are 5-6px **squares** (website idiom): `.local-indicator > span` 5px, `.metric-dot` and `.audit-dot` 6px.
- Lines are 1px (`--line-soft`/`--line`/`--line-strong`); accent bars are 2px left borders (`.citation`, `.chat-question`, `.context-note`, `#company-home-harnesses > .artifact-row`, `.notice` variants). No blurred shadows anywhere.
- Corner markers (website machine-window idiom, re-implemented): parent `position: relative; border: 1px solid var(--line-strong)`; `::before, ::after { content: ""; position: absolute; z-index: 1; width: 5px; height: 5px; border: 1px solid var(--accent-border); background: var(--surface-0); pointer-events: none }`, `::before { top: -3px; left: -3px }`, `::after { right: -3px; bottom: -3px }`. Required on `.login-card` (it gets `background: var(--surface-1); border: 1px solid var(--line-strong); padding: 32px 28px; box-shadow: 6px 6px 0 var(--accent-tint-3)` — the only spacing addition allowed; `.login-story` is full-bleed so its markers would clip, it carries the dot lattice instead). Optional, only if the E2E screenshots show no overlap: `.panel:not(details):not(.panel .panel)`.
- Dot lattice for `.login-story` only: `background: var(--surface-0) radial-gradient(circle, var(--text-subtle) .8px, transparent 1px) 0 0 / 10px 10px; border-right: 1px solid var(--line)` (at <=650 `border-right: 0; border-bottom: 1px solid var(--line)`).
- Focus: `:is(a, button, summary, input, select, textarea, [tabindex]):focus-visible { outline: var(--focus-ring); outline-offset: var(--focus-offset) }`; inputs additionally `:focus { border-color: var(--accent); box-shadow: none }`. The company/corpus `3px/4px` overrides become the same `2px/3px`.
- Selection `::selection { background: var(--selection-bg); color: var(--selection-fg) }`.
- Motion: `@keyframes signal-blink { 0%, 72%, 100% { opacity: 1 } 82% { opacity: .35 } }`; `.local-indicator > span { animation: signal-blink var(--blink) ease-in-out infinite; box-shadow: 0 0 9px var(--accent-glow) }`; controls `transition: background var(--duration) ease, border-color var(--duration) ease, color var(--duration) ease`; delete `.button:hover { transform: translateY(-1px) }`. Keep the existing `@media (prefers-reduced-motion: reduce)` rule and add `.local-indicator > span { opacity: 1 }` inside it. `assets/js/app.js` line 128 becomes `topbar.config({barColors: {0: "#bbff62"}, shadowColor: "rgba(0, 0, 0, 0)"})`.
- Scrollbars: `* { scrollbar-color: var(--line-strong) var(--surface-0); scrollbar-width: thin }`; `::-webkit-scrollbar { width: 10px; height: 10px } ::-webkit-scrollbar-thumb { background: var(--line-strong); border: 2px solid var(--surface-0) } ::-webkit-scrollbar-track { background: var(--surface-0) }`.
