# clamp

Implement Clamp(value, lo, hi int) int with inclusive bounds. Inputs always satisfy lo <= hi.

The candidate seed deliberately contains a bug. Protected checks belong to the evaluator and must be mounted outside candidate-writable storage. A successful model message is not a passing grade.

This finite suite accepts only package `utility` and the declared `Clamp` function with its existing integer signature. Use no imports, extra functions, package variables, initializers, printing, goroutines, or compiler directives. Edit `utility.go` only.
